## 1. Audit & Usability Review of Flash 3.8's Original Prompts

The baseline prompt kit generated by Google Flash 3.8 provided a strong foundation, but had several critical gaps when evaluated against **this specific codebase** and **your beginner learning journey**:

| Original Flaw | Why It Was a Problem | How We Improved It |
| :--- | :--- | :--- |
| **Missing `repositories/` Layer** | Flash 3.8 asked to scan generic connection logic, assuming controllers talk directly to SQL. In reality, this app has 7 dedicated domain repositories. | Prompts now explicitly target `repositories/`, teaching you the Repository Pattern. |
| **Missing View Contract & `e()` Helper** | Flash 3.8 mentioned raw `htmlspecialchars`. The codebase actually uses `views/view_contract.php` and the null-safe `e()` helper in `views/helpers.php`. | Updated prompts to extract the View Contract and null-safe escaping mechanism. |
| **Omitted CSRF & Session Guards** | Flash 3.8 ignored the `csrf_token()`, `csrf_field()`, and `csrf_verify()` pipeline in `bootstrap.php`. | Added explicit CSRF token audit to the security prompt. |
| **Missing Frontend Pipeline** | Flash 3.8 omitted the frontend completely (HTML/Tailwind/JS), leaving you in the dark on how views and JS talk to PHP. | Added **Prompt 4: Frontend Pipeline**, covering Tailwind CLI compilation, `pms.css` tokens, and `dashboard.js`. |
| **Language Too Abstract for Beginners** | Terms like *"data state mutations"* and *"execution lifecycle"* generate high-level academic theory instead of practical code explanations. | Injected instructions commanding the AI to use plain English, concrete analogies, line-by-line breakdowns, and viva defense tips. |
| **Folder Splitting** | Directed files to an unignored `./obsidian-study-vault/` directory. | Standardized path to `./docs/study-vault/` (which is safely ignored in `.gitignore` and `.antigravityignore`). |

